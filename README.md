# 🤖 Rule-Based AI Chatbot

A simple and interactive **Rule-Based AI Chatbot built using Python** as part of my Artificial Intelligence Internship at **DecodeLabs**.

The chatbot uses predefined rules, conditional logic, and a response dictionary to simulate a basic conversational experience. It can handle common conversations, perform mathematical calculations, provide the current date and time, and gracefully handle invalid or unknown inputs.

## 🚀 Project Overview

This project demonstrates the fundamental concepts behind rule-based artificial intelligence.

Instead of using machine learning or a large language model, the chatbot follows predefined rules and conditions to determine how it should respond to different user inputs.

The chatbot runs continuously in the terminal until the user enters an exit command.
